## Latest work

| Project | What it does |
|---|---|
| **[Agent Flight Recorder](https://github.com/kmsmohamedansar/agent-flight-recorder)** | A local black-box recorder for AI agents. It captures tool calls, failures, file changes, and optional Git context in SQLite, then links a failure to the evidence most likely to have caused it. Published on PyPI as `flightrecorder-ai`, with a CLI, local timeline UI, replay tapes, benchmarks, and an optional MCP adapter. |
| **[StoryEra](https://github.com/kmsmohamedansar/storyera)** | An installable agent skill for auditing continuity across novels and series. It builds a cited fact ledger, separates contradictions from explained changes and intentional mysteries, and suggests minimal repairs without editing the manuscript. Includes a real three-volume case study and behavioral evaluations. |
| **[REA study](https://github.com/kmsmohamedansar/rea-study)** | A controlled study of whether REA—an agent tool for inspecting programs without source code—improves explanation accuracy. The full experiment, held-out evaluation, raw results, claims ledger, and reproducible report are public. |
| **[Site Recon](https://github.com/kmsmohamedansar/site-recon)** | An agent skill and optional Playwright inspector that explains a site's public frontend stack and animations, labels inference, and produces clean-room reproduction recipes rather than pretending compiled bundles are original source. |
| **[Authorized Web Exposure Audit](https://github.com/kmsmohamedansar/authorized-web-exposure-audit)** | An authorization-first agent skill for reviewing accidental exposure on a website's public surface. It uses bounded unauthenticated requests, strict scope files, redaction, stop conditions, and a deliberately vulnerable localhost fixture for safe demonstrations. |
